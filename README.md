# Рус тили

Рус тилини ўрганиш учун мобил сайт: **Мавзулар · Машқлар · Луғатлар · Тестлар**.
Интерфейс ўзбек тилида (кирилл), ўрганиладиган матн русча — урғу белгилари билан.

**Сайт:** https://samandarsaidjonov.github.io/rus-tili-quiz/

| Бўлим | Нима бор |
|---|---|
| Мавзулар | 9 та мавзу: 6 та падеж ва 3 та феъл мавзуси (настоящее время, прошедшее время, возвратные глаголы). Фақат тушунтириш ва жадваллар, машқ йўқ |
| Машқлар | Мавзулар бўйича ва аралаш тўпламлар (~870 та машқ). Жавобни рус ҳарфларида ўзингиз ёзасиз, текширув юмшоқ |
| Луғатлар | Савол ўзбекча, 4 та жавоб варианти русча. «Хато қилганларим» режими бор |
| Тестлар | 10 та тест, ҳар бирида 10 та 4 вариантли савол. Натижа охирида чиқади |

Прогресс шу браузернинг `localStorage` ида сақланади — аккаунт ва сервер йўқ.
1-версиянинг прогресси автоматик кўчирилади.

## Ишлаб чиқиш

```bash
npm install
npm run dev        # http://localhost:4321/rus-tili-quiz/
npm run check      # контентни текшириш
npm test           # unit тестлар
npm run e2e        # Playwright (телефон экрани)
npm run build
```

Технологиялар: Astro + TypeScript, Preact оролчалари, контент — `src/content` ичидаги
JSON ва MDX файлларда. Деплой: GitHub Actions → GitHub Pages.

Дизайн токенлари ва услублар: `src/styles/global.css`, қоидалар — `CLAUDE.md` нинг 7-бўлимида.

Контент қўшиш ва лойиҳа қоидалари: [`CLAUDE.md`](CLAUDE.md).
Батафсил ҳужжатлар: [`docs/`](docs/).
