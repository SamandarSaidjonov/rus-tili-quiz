# Рус тили сўз квизи

Рус тили дафтаридаги сўзлар бўйича квиз, дарсларга бўлинган:

- **1-дарс:** вақт ва об-ҳаво (110 та сўз ва ибора)
- **2-дарс:** феъллар (75 та, ҳар бирига мисол гап ва изоҳ)
- **Машқлар · Падежлар:** 81 та машқ, 8 хил (таржима, хатони тўғрилаш, қўшимча, қавсдаги сўз, предлог, олмош, сифат, падежни топиш). Жавоб қўлда ёзилади.

Дарсларда савол ўзбекча берилади, 4 та жавоб варианти русча. Натижа ҳар бир фойдаланувчининг ўз браузерида сақланади.
