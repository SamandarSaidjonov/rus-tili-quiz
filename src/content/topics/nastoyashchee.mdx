## Қисқача

Настоящее время (ҳозирги замон) — ҳозир бўлаётган ёки доим, ҳар куни бўладиган иш.

**Ўзбек тилидан фарқи:** русчада битта шакл ўзбекчадаги иккита шаклга тўғри келади.
Я чита́ю — «ўқияпман» ҳам, «ўқийман» ҳам. Қайсиси эканини гапнинг ўзи айтади:
сейча́с (ҳозир) ёки ка́ждый день (ҳар куни).

Феълнинг охири **шахсга** қараб ўзгаради: я чита́ю, ты чита́ешь, они́ чита́ют.

**Қаерда хато қилинади:**
- шахс қўшимчасини адаштириш: «я хо́чет» эмас, **я хочу́**;
- 1- ва 2-спряжениени адаштириш: «они́ говору́т» эмас, **они́ говоря́т**;
- совершенный вид феълидан ҳозирги замон ясаш: **прочита́ю** — бу ҳозирги эмас, келаси замон.

## Қандай ясалади

Икки қадам:
1. Инфинитивдан **-ть** ни олиб ташланг (2-спряжениеда **-ить**, **-еть** ни): чита́ть → чита-,
   говори́ть → говор-.
2. Шахсга қараб қўшимча қўшинг. Қўшимчалар икки хил бўлади: **1-спряжение** ва **2-спряжение**.

### 1-спряжение: -ю, -ешь, -ет, -ем, -ете, -ют

| Лицо | чита́ть |
|---|---|
| я | чита́<b class="rt-end">ю</b> |
| ты | чита́<b class="rt-end">ешь</b> |
| он, она́ | чита́<b class="rt-end">ет</b> |
| мы | чита́<b class="rt-end">ем</b> |
| вы | чита́<b class="rt-end">ете</b> |
| они́ | чита́<b class="rt-end">ют</b> |

Ундошдан кейин **-ю** ўрнига **-у**, **-ют** ўрнига **-ут** ёзилади: живу́, живу́т; пишу́, пи́шут.

### 2-спряжение: -ю, -ишь, -ит, -им, -ите, -ят

| Лицо | говори́ть |
|---|---|
| я | говор<b class="rt-end">ю́</b> |
| ты | говор<b class="rt-end">и́шь</b> |
| он, она́ | говор<b class="rt-end">и́т</b> |
| мы | говор<b class="rt-end">и́м</b> |
| вы | говор<b class="rt-end">и́те</b> |
| они́ | говор<b class="rt-end">я́т</b> |

**ж, ш, ч, щ** дан кейин **-ю** ўрнига **-у**, **-ят** ўрнига **-ат** ёзилади: учу́, у́чат;
спешу́, спеша́т; слы́шу, слы́шат.

### Феълнинг спряжениесини қандай билиш мумкин

1. **-ить** билан тугаса — кўпинча **2-спряжение**: говори́ть, звони́ть, по́мнить, учи́ть.
   Истиснолар: **жить, пить, брить** — 1-спряжение (живу́, живёшь; пью, пьёшь).
2. Еттита **-еть** ли феъл — 2-спряжение: смотре́ть, ви́деть, ненави́деть, зави́сеть, верте́ть,
   оби́деть, терпе́ть.
3. Тўртта **-ать** ли феъл — 2-спряжение: гнать, держа́ть, дыша́ть, слы́шать.
4. **Қолганлари — 1-спряжение**: чита́ть, де́лать, ду́мать, знать, слу́шать, име́ть, сожале́ть.

**Диққат:** име́ть ва сожале́ть **-еть** билан тугайди, лекин рўйхатда йўқ, шунинг учун
1-спряжение: име́ю, име́ешь; сожале́ю, сожале́ешь.

### -ова- / -ева- ли феъллар

**-ова-** (ёки **-ева-**) тушиб қолади, ўрнига **-у-** келади. Кейин 1-спряжение қўшимчаси қўшилади.

| Инфинитив | я · ты · они́ |
|---|---|
| рисова́ть | рис<b class="rt-end">у́</b>ю, рису́ешь, рису́ют |
| сове́товать | сове́т<b class="rt-end">у</b>ю, сове́туешь, сове́туют |
| испо́льзовать | испо́льз<b class="rt-end">у</b>ю, испо́льзуешь, испо́льзуют |
| чу́вствовать | чу́вств<b class="rt-end">у</b>ю, чу́вствуешь, чу́вствуют |

### -ава- ли феъллар

**-ва-** тушиб қолади: дава́ть → даю́. Бу феълларда ты шаклида **-ёшь** ёзилади.

| Инфинитив | я · ты · они́ |
|---|---|
| дава́ть | да<b class="rt-end">ю́</b>, даёшь, даю́т |
| узнава́ть | узна<b class="rt-end">ю́</b>, узнаёшь, узнаю́т |
| встава́ть | вста<b class="rt-end">ю́</b>, встаёшь, встаю́т |

## Қачон ишлатилади

1. **Ҳозир, гапираётган пайтда бўлаётган иш.**
   Сейча́с я чита́ю. — Ҳозир мен ўқияпман.

2. **Доим, ҳар куни, тез-тез бўладиган иш.**
   Ка́ждый ве́чер я звоню́ ма́ме. — Ҳар оқшом онамга қўнғироқ қиламан.

3. **Умуман тўғри бўлган нарса, одат, касб.**
   Брат рабо́тает в ба́нке. — Акам банкда ишлайди.

4. **Билиш, ёқтириш, хоҳлаш.**
   Я зна́ю э́то сло́во. — Мен бу сўзни биламан.

### Диққат: совершенный вид феълларида ҳозирги замон йўқ

Луғатдаги кўп феъллар жуфт бўлиб келади: **чита́ть / прочита́ть**, **звони́ть / позвони́ть**,
**де́лать / сде́лать**. Биринчиси — несовершенный вид, иккинчиси — совершенный вид.

Совершенный вид феълининг «ҳозирги замонга ўхшаган» шакли аслида **келаси замон**:

| Шакл | Маъноси |
|---|---|
| я чита́ю | ўқияпман, ўқийман (ҳозирги) |
| я прочита́ю | ўқиб чиқаман (келаси) |
| я звоню́ | қўнғироқ қиляпман (ҳозирги) |
| я позвоню́ | қўнғироқ қиламан (келаси) |
| я де́лаю | қиляпман (ҳозирги) |
| я сде́лаю | қилиб қўяман (келаси) |
| я покупа́ю | сотиб оляпман (ҳозирги) |
| я куплю́ | сотиб оламан (келаси) |

Шунинг учун «Сейча́с я прочита́ю» деб бўлмайди. Ҳозир бўлаётган иш учун доим жуфтнинг
**биринчи** феълини олинг: Сейча́с я **чита́ю**.

## Истиснолар

### Ҳарф алмашиши (2-спряжение, фақат «я» шаклида)

Бу феълларда **фақат я** шаклида ўзакдаги ҳарф алмашади, қолган шакллар оддий.

| Инфинитив | я · ты |
|---|---|
| ходи́ть | хо<b class="rt-end">ж</b>у́, хо́дишь (д → ж) |
| ви́деть | ви́<b class="rt-end">ж</b>у, ви́дишь (д → ж) |
| плати́ть | пла<b class="rt-end">ч</b>у́, пла́тишь (т → ч) |
| проси́ть | про<b class="rt-end">ш</b>у́, про́сишь (с → ш) |
| люби́ть | люб<b class="rt-end">л</b>ю́, лю́бишь (б → бл) |
| гото́вить | гото́в<b class="rt-end">л</b>ю, гото́вишь (в → вл) |

Луғатдаги феъллар ҳам шундай: переводи́ть → перевожу́, тра́тить → тра́чу, ста́вить → ста́влю,
лови́ть → ловлю́.

|---|---|

**мочь:** я ва они́ шаклида **г**, қолганида **ж**: могу́, мо́жешь, мо́жет, мо́жем, мо́жете, мо́гут.
**писа́ть:** ҳамма шаклда **с** ўрнига **ш**: пишу́, пи́шешь, пи́шут.

## Урғу кўчадиган феъллар

Бу феълларда «я» шаклида урғу охирида, қолган шаклларда эса ўзакда туради.

| я | ты (ва бошқалари) |
|---|---|
| пишу́ | пи́шешь, пи́шут |
| учу́ | у́чишь, у́чат |
| люблю́ | лю́бишь, лю́бят |
| смотрю́ | смо́тришь, смо́трят |
| могу́ | мо́жешь, мо́гут |
| хожу́ | хо́дишь, хо́дят |
| плачу́ | пла́тишь, пла́тят |
| прошу́ | про́сишь, про́сят |

**Диққат:** **плачу́** (тўлайман, плати́ть) ва **пла́чу** (йиғлаяпман, пла́кать) фақат урғуси
билан фарқ қилади.

## Эслаб қолинг

- Я чита́ю — «ўқияпман» ҳам, «ўқийман» ҳам: русчада битта шакл.
- 1-спряжение: -ю, -ешь, -ет, -ем, -ете, -ют. 2-спряжение: -ю, -ишь, -ит, -им, -ите, -ят.
- **-ить** — кўпинча 2-спряжение; жить, пить — 1-спряжение.
- -ова- → -у-: рису́ю, сове́тую. 2-спряжениеда «я» шаклида ҳарф алмашади: хожу́, люблю́.
- Совершенный вид (прочита́ть, позвони́ть) ҳозирги замонда ишлатилмайди: прочита́ю — келаси замон.
