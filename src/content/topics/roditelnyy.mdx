## Қисқача

Родительный падеж — энг кўп ишлатиладиган падеж. У асосан **эгалик** («акамнинг китоби») ва
**йўқлик** («вақтим йўқ») маъносини беради.

Ўзбек тилидаги яқин қўшимчалар: **-нинг** (кни́га бра́та — акамнинг китоби) ва
**-дан** (из ба́нка — банкдан).

**Қаерда хато қилинади:**
- «нет» дан кейин доим родительный туради: нет **вре́мени**, нет **де́нег**;
- 2, 3, 4 дан кейин бирликда: два **бра́та**, 5 дан бошлаб кўпликда: пять **бра́тьев**;
- кўпликда қўшимча кўпинча тушиб қолади: кни́га → **книг**, ко́мната → **ко́мнат**.

| Савол | Ўзбекча | Мисол |
|---|---|---|

| чего? | ниманинг? нимаси? | Чего́ нет? — Нет де́нег. |
| откуда? | қаердан? | Отку́да ты? — Из Ташке́нта. |

## Қачон ишлатилади

1. **Эгалик: кимнинг, ниманинг.**
   Э́то кни́га **бра́та**. — Бу акамнинг китоби.

2. **Йўқлик: нет, не́ было, не бу́дет.**
   У меня́ нет **вре́мени**. — Менинг вақтим йўқ.

3. **Миқдор: мно́го, ма́ло, не́сколько, ско́лько.**
   У нас мно́го **рабо́ты**. — Бизда иш кўп.

4. **Сонлардан кейин.** 2, 3, 4 — бирликда; 5 дан юқориси — кўпликда.
   два **бра́та**, пять **бра́тьев**; два **дня**, семь **дней**.

5. **Предлоглар билан:** у, из, от, до, без, для, о́коло, по́сле, кро́ме, про́тив.
   Я иду́ из **ба́нка**. — Мен банкдан кетяпман.

6. **Сана ва вақт.**
   С **ма́рта** до **ма́я**. — Мартдан майгача.

7. **Баъзи феъллардан кейин:** ждать, боя́ться, жела́ть, проси́ть, достига́ть.
   Я жду **отве́та**. — Мен жавоб кутяпман.

## Сифатлар (прилагательное) қўшимчалари

| Род / число | Қўшимча | Мисол |
|---|---|---|
| мужской, средний | -ого / -его | у но́вого дире́ктора · у си́него до́ма |
| женский | -ой / -ей | у но́вой колле́ги · у си́ней ру́чки |
| множественное | -ых / -их | у но́вых клие́нтов · у ру́сских студе́нтов |

**Диққат:** -ого ва -его қўшимчасидаги **г** ҳарфи **в** деб ўқилади: но́вого — «но́вава».

| Именительный | Родительный | Предлогдан кейин |
|---|---|---|
| я | меня́ | у меня́ |
| ты | тебя́ | у тебя́ |
| он | его́ | у **него́** |
| она́ | её | у **неё** |
| оно́ | его́ | у **него́** |
| мы | нас | у нас |
| вы | вас | у вас |
| они́ | их | у **них** |
| кто | кого́ | у кого́ |
| что | чего́ | без чего́ |

**н- қоидаси:** 3-шахс олмошлари предлогдан кейин **н-** билан бошланади:
его́ → у **него́**, её → для **неё**, их → о́коло **них**.

## Эслаб қолинг

- Саволлари: **кого? чего?** Маъноси: -нинг, -дан, «йўқ».
- **нет / не́ было / не бу́дет** дан кейин доим родительный.
- Предлоглар: **у, из, от, до, без, для, о́коло, по́сле, кро́ме, про́тив**.
- 2–4 → бирлик родительный, 5 дан юқори → кўплик родительный.
- Женский родда кўпликда қўшимча тушади: кни́га → книг, ко́мната → ко́мнат.
