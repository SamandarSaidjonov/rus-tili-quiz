# TestResult

Тестлар рўйхати (ҳолати билан) ва тест охиридаги натижа: балл ва ҳар бир савол бўйича «Сизнинг жавобингиз / Тўғри жавоб / Изоҳ».

**Белгилаш:** рўйхат `rt-tests` → `<a class="rt-test">` + `rt-badge`. Натижа `rt-card` → `rt-score` → `<ol class="rt-review">` (ҳар бир `li` да `rt-review__q` ва `dl`).

**Белгилар (badge):** `rt-badge--todo` «Топширилмаган», `rt-badge--score` охирги балл «8/10», `rt-badge--ok` ✓ «Тўғри», `rt-badge--no` ✗ «Хато».

**Қоидалар**
- Тест номи «Тест 1», «Тест 2» … Рўйхатда охирги балл ва остида энг яхши натижа.
- Тест пайтида тўғри/хато кўрсатилмайди (OptionList `is-selected`). Натижа фақат охирида.
- Ҳар бир савол бўйича учала қатор доим бор, изоҳ ҳам.
- «Қайта топшириш» иккинчи даражали тугма; энг яхши ва охирги натижа сақланади.
