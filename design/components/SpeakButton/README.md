# SpeakButton

Русча сўз ёки гапни Web Speech API (`ru-RU`) орқали ўқиб берадиган думалоқ тугма.

**Белгилаш:** `<button class="rt-say" type="button" aria-label="Тинглаш">` ичида `speaker` иконкаси. Гап ичида кичик ўлчами: `rt-say rt-say--sm`.

**Истеъмолчи беради:** ўқиладиган матн (урғу белгиси билан ҳам ўқийверади) ва `speechSynthesis` чақириш.

**Қоидалар**
- Қурилмада `ru-RU` овози бўлмаса, тугма умуман кўрсатилмайди.
- Катта ўлчам (44px) карточка сарлавҳаси ёнида, кичиги (36px) мисол гап ва «Тўғри жавоб» охирида.
- `aria-label="Тинглаш"` доим бўлсин: тугмада ёзув йўқ.
