# Feedback

Жавобдан кейинги панел: вердикт, фойдаланувчи жавоби, тўлиқ тўғри гап, талаффуз ва изоҳ.

**Белгилаш:** `<section class="rt-feedback is-correct|is-wrong" role="status">` → `rt-verdict` (✓/✗ иконкаси + «Тўғри!»/«Хато») → `rt-given` → `rt-right` (`rt-answer` + SpeakButton) → `rt-explain`.

**Истеъмолчи беради:** фойдаланувчи жавоби, тўғри гап (жавоб қисми `<b>` ичида), фойдаланувчи топа олмаган сўзлар (`<mark>`, LCS бўйича), изоҳ матни.

**Қоидалар**
- Вердикт доим иконка + сўз: ранг ёлғиз ўзи ҳолатни билдирмайди.
- «Билмайман, жавобни кўрсат» босилганда вердикт «Жавоб кўрсатилди», панел `is-wrong`, `rt-given` йўқ.
- Изоҳда учта нарса бор: қайси падеж, нега (савол ёки предлог) ва қайси ҳарф ўзгарди («-а ўрнига -е»).
- Грамматик атамалар русча, изоҳ ўзбекча. Изоҳдаги русча сўзлар `lang="ru"`.
- Ўтган саволни кўришда вердикт кичик: «Бу машқда хато қилгансиз».
