# Chip

Танлов тугмаси: луғат тўпламлари (кун, бир нечта кун, ҳаммаси, «Хато қилганларим»), машқ тури ва саволлар сонини танлаш учун.

**Белгилаш:** `<button class="rt-chip" aria-pressed="true|false">`. Танланганида олдига `check` иконкаси қўйилади. Сони `rt-chip__count` ичида. Гуруҳни `<div class="rt-chips" role="group" aria-labelledby="…">` ўрайди.

**Қоидалар**
- Танланган ҳолат уч белги билан кўринади: `accent-soft` фон, `accent` чегара ва ✓ иконкаси, ёзув қалин.
- Ёзув ўзбекча, қисқа. Сана «18-ноябр» шаклида.
- Битта танлов бўладиган гуруҳда ҳам `aria-pressed` ишлатилади, бошқаси танланганда олдингиси `false` бўлади.
