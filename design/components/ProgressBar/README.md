# ProgressBar

Квиз, машқ ёки тест ичидаги ўрин: «4 / 10», чизиқ ва ✓/✗ ҳисоби.

**Белгилаш:** `rt-progress` ичида `rt-progress__pos`, `rt-bar` (ичида `<i style="width:…%">`) ва `rt-tally`. Бош саҳифадаги бўлим карточкасида фақат `rt-bar` ишлатилади.

**Истеъмолчи беради:** жорий савол рақами, жами, жавоб берилганлар, тўғри ва хато сони.

**Қоидалар**
- Чизиқ `accent` рангида: у тўғри ёки хато эмас, фақат олға силжишни кўрсатади.
- Тест пайтида `rt-tally` кўрсатилмайди (тўғри/хато охиригача яширин).
- Чизиқ `role="progressbar"` ва `aria-valuenow` билан.
