# Button

Тугма: `rt-btn--primary` экрандаги асосий иш учун, `rt-btn--secondary` иккинчи даражали иш учун, `rt-link` эса кам ишлатиладиган иш учун.

**Белгилаш:** `<button class="rt-btn rt-btn--primary" type="button">Текшириш</button>`. Тўлиқ кенглик учун `rt-btn--block` қўшинг. Ҳавола бўлса, `<a class="rt-btn …">` ишлатинг.

**Қачон ишлатилади**
- `rt-btn--primary` экранда битта бўлади: «Текшириш», «Кейинги →», «Тестни бошлаш», «Натижани кўриш».
- `rt-btn--secondary`: «← Олдинги», «Қайта топшириш», «Кўриш режими».
- `rt-link`: «Билмайман, жавобни кўрсат», «Жорий саволга қайтиш».
- Ёзувсиз думалоқ тугма (тема, прогрессни тозалаш) бу ерда эмас — IconButton да.

**Қоидалар**
- Ёзув феълдан бошланади ва қисқа бўлади. Йўналиш ўқлари матнда туради: «← Олдинги», «Кейинги →».
- Баландлиги камида `tap-min` (48px). Тугмани ўчириб қўйманг (`disabled`): жавоб бўш бўлса, «Текшириш» босилганда огоҳлантириш чиқади (AnswerField).
- Ранг: фон `accent`, ҳовер `accent-strong`, ёзув `on-accent`. Тўғри ёки хато ранглари тугмада ишлатилмайди.
