# TopBar

Машқ, луғат квизи ёки тест экранининг юқори қисми: ортга қайтиш, бўлим номи ва прогресс.

**Белгилаш:** `rt-topbar` → `rt-topbar__row` (`rt-back` ҳавола ва сарлавҳа) → ProgressBar.

**Қоидалар**
- `rt-back` рўйхатга қайтаради, олдинги саволга эмас. Олдинги савол учун QuizNav'даги «← Олдинги» тугмаси бор.
- `rt-back` да `aria-label` қаерга қайтишини айтсин: «Машқлар рўйхатига қайтиш».
- Сарлавҳа бир қатор, сиғмаса `…` билан қирқилади.
