# GrammarTable

Мавзулардаги грамматик жадвал: отлар, сифатлар ва олмошлар қўшимчалари, предлоглар, феъллар.

**Белгилаш:** `<div class="rt-table-wrap" role="region" aria-label="…" tabindex="0">` → `<table class="rt-table">`. Устун сарлавҳаси `<th scope="col">`, бир нечта қаторни бирлаштирган род сарлавҳаси `<th scope="rowgroup" rowspan="…">`. Русча катак `<td lang="ru">`, қўшимча `<b class="rt-end">`.

**Қоидалар**
- Телефонда жадвал ён томонга сурилади (`rt-table-wrap`), саҳифа эмас. Жадвалнинг энг кичик кенглиги 440px.
- Ҳар бир катакда мисол сўз, қўшимчаси `rt-end` (қалин, `accent`). Урғу белгиси қўшимча ичида қолади: `стол<b class="rt-end">е́</b>`.
- Сарлавҳалардаги грамматик атамалар русча: род, единственное число, множественное число.
- Истиснолар жадвал остида `rt-table-caption` ичида, ҳарфлар орқали.
