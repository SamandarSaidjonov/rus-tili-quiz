# TopicBlocks

Мавзу саҳифасининг қисмлари: сарлавҳа, қисқача, саволлар, мисол гаплар, кўп учрайдиган хатолар, «Эслаб қол» ва мавзулар орасида юриш.

**Белгилаш:** `<article class="rt-topic">` ичида: `h1` (`title-xl`), `rt-lead`, `h2` (`title-lg`), `rt-questions`, `rt-examples` (ҳар бири `rt-example`), GrammarTable, `rt-mistakes` (`rt-mistake--no` + `rt-mistake--ok`), `rt-remember`, `rt-pager`.

**Падеж саҳифасидаги тартиб:** Қисқача → Саволлари → Қачон ишлатилади → Предлоглар → Феъллар → Отлар қўшимчалари → Сифатлар → Олмошлар → Мисол гаплар → Кўп учрайдиган хатолар → Эслаб қол → Олдинги/Кейинги мавзу.

**Қоидалар**
- Мавзулар бўлимида машқ, тест ёки вариантли савол йўқ: фақат матн ва жадвал.
- Абзац кенглиги `read-max` (68ch), китобдек ўқилсин.
- Хатолар «нотўғри → тўғри» жуфти: ✗ иконкаси ва устидан чизилган гап, кейин ✓ иконкаси ва тўғри гап. Гап матни `ink` рангида, ҳолатни иконка ташийди.
- «Эслаб қол» 3–5 қатор, `accent-soft` фонда.
