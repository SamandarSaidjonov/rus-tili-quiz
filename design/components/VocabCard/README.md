# VocabCard

Луғатнинг кўриш режимидаги сўз карточкаси: русча сўз, ўзбекча таржима, сўз туркуми, мисол гап ва изоҳ.

**Белгилаш:** `rt-card` → `rt-vocab__head` (`rt-vocab__pos`, `rt-vocab__ru`, `rt-vocab__uz`, SpeakButton) → `rt-example` → `rt-note`.

**Истеъмолчи беради:** сўз маълумоти (`ru`, `uz`, `pos`, `ex`, `exUz`, `note`). Мисолдаги асосий сўз `<b>` ичида.

**Қоидалар**
- Русча матн доим `lang="ru"` билан ва урғу белгиси билан (U+0301).
- Сўз туркуми русча атама: глагол, существительное, наречие, прилагательное.
- Изоҳ ҳар бир сўзда бор. Изоҳ ичидаги русча мисоллар ҳам `lang="ru"`.
- Квиздан кейинги изоҳ ҳам шу тузилишда (OptionList остида).
