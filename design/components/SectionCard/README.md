# SectionCard

Бош саҳифадаги бўлим карточкаси: иконка, ном, прогресс матни ва чизиғи.

**Белгилаш:** `<a class="rt-section">` → `rt-section__icon`, сарлавҳа (`rt-section__title`), `rt-section__meta`, `rt-bar`, `chevron-right`.

**Истеъмолчи беради:** бўлим номи, иконкаси ва `localStorage` дан ҳисобланган прогресс.

**Қоидалар**
- Бош саҳифада тўртта бўлим BottomNav тартибида.
- Прогресс матни «N та …дан M таси …» шаклида, ҳали бошланмаган бўлса «Ҳали бошланмаган».
- Иконка фони `accent-soft`, иконка `accent`.
