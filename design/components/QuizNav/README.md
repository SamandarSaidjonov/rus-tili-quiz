# QuizNav

Савол остидаги ҳаракатлар қатори: «← Олдинги» ва «Кейинги →».

**Белгилаш:** `rt-actionbar` → `rt-actions` (иккинчи даражали ва асосий Button). Ўтган савол кўрилаётганда тепасида `rt-reviewing`.

**Қоидалар**
- **Автоматик ўтиш йўқ.** Жавоб тўғри бўлса ҳам «Кейинги →» ни фойдаланувчи ўзи босади.
- Жавоб берилмагунча асосий тугма «Текшириш» (машқ) ёки йўқ (4 вариантли савол: вариант босилганда жавоб берилади).
- «← Олдинги» ўтган саволни фақат кўриш учун очади, қайта жавоб бериб бўлмайди. Биринчи саволда кўрсатилмайди.
- Охирги саволда асосий тугма ёзуви «Натижани кўриш →».
- Мобилда бу қатор BottomNav устида ёпишиб туради (`position: sticky`).
