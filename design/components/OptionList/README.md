# OptionList

4 та вариантли савол: луғат квизи, `choose` тури машқлар ва тест саволлари.

**Белгилаш:** `<ol class="rt-options">` ичида `<button class="rt-option">` → `rt-option__key` (1–4), `rt-option__text` (`lang="ru"`), `rt-option__mark`. Ҳолат класслари: `is-selected`, `is-correct`, `is-wrong`, `is-dim`.

**Ҳолатлар**
- **Жавобдан олдин:** оддий, ҳовер ва фокусда `accent` чегара. Компьютерда 1–4 тугмалари ишлайди.
- **Жавобдан кейин (квиз ва машқ):** тўғри вариант `is-correct` + ✓, танланган хато вариант `is-wrong` + ✗ + устидан чизилган, қолганлари `is-dim`. Ҳаммаси `disabled`.
- **Тестда:** танланган вариант `is-selected`, тўғри/хато тест охиригача кўрсатилмайди.

**Қоидалар**
- Савол ўзбекча (`rt-prompt-uz` + `rt-prompt-ctx` «Гапда: …»), вариантлар русча.
- Нотўғри вариантлар маъно ёки ёзилиши бўйича яқин бўлсин, лекин иккита тўғри жавоб бўлмасин (`CONFLICT` жуфтлари бирга чиқмайди).
- Тестда вариантлар тартиби аралашади, саволлар тартиби эса қатъий.
- Ҳолат ранг билан бирга иконка ва чизиш билан кўрсатилади; `rt-sr` ичида «тўғри»/«хато» сўзи бор.
