# IconButton

Ёзувсиз думалоқ тугма: бош саҳифа сарлавҳасининг ўнг четида — темани алмаштириш (`rt-iconbtn`)
ва барча прогрессни тозалаш (`rt-iconbtn rt-iconbtn--danger`).

**Белгилаш:** `<button class="rt-iconbtn" type="button" aria-label="Темани алмаштириш">…</button>`.
Тугмалар `rt-pagehead__end` ичида, `<h1>` дан кейин туради.

**Қачон ишлатилади**
- Экранда доим кўриниб туриши керак, лекин сарлавҳадан кўп жой олмаслиги керак бўлган иш учун.
- Иши бир сўз билан айтилмайдиган бўлса, бу тугма эмас, `rt-btn--secondary` ёки `rt-link` керак.

**Қоидалар**
- Ёзуви йўқ, шунинг учун `aria-label` **шарт** — иконканинг ўзи маъно ташимайди. Компьютерда
  изоҳ чиқиши учун `title` ҳам ўша ёзув билан берилади.
- Ўлчами `tap-min` (48px), иконка 22px. Ранги `muted`, устига борганда `ink` ва фон `surface-sunk`.
- `rt-iconbtn--danger` — қайтмас иш (прогрессни ўчириш): устига борганда `bad` рангга киради ва
  босилганда `confirm` сўрайди.
- Тема тугмасида иккала иконка ҳам белгиланишда туради, қайси бири кўриниши CSS орқали
  ҳал бўлинади (`.rt-theme__sun`, `.rt-theme__moon`): қоронғи темада қуёш (ёруғга ўтиш),
  ёруғ темада ой (қоронғига ўтиш). Шунинг учун саҳифа очилганда иконка сакрамайди.
