# BottomNav

Доимий пастки навигация: Мавзулар · Машқлар · Луғатлар · Тестлар.

**Белгилаш:** `<nav class="rt-nav" aria-label="Бўлимлар">` ичида тўртта `<a class="rt-nav__item">` (иконка + ёзув). Жорий бўлимда `aria-current="page"`.

**Қоидалар**
- Тартиб ва номлар ўзгармайди. Иконкалар: `book`, `pencil`, `cards`, `test`.
- Саҳифада `position: fixed; bottom: 0`. Контент пастида `nav-height` + `space-12` бўш жой қолдиринг.
- Жорий бўлим уч белги билан ажралади: `accent` ранг, қалин ёзув ва тепадаги чизиқ.
- Машқ ёки тест ичида ҳам кўринади, лекин QuizNav унинг устида туради.
