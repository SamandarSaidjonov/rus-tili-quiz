# ExercisePrompt

Машқ шарти: кўрсатма ва машқ белгилари билан ёзилган гап.

**Белгилаш:** `rt-exercise` → `rt-label` (кўрсатма) → `rt-sentence` (`lang="ru"`) ёки таржима учун `rt-prompt-uz`. Маълумотдаги белгилар шундай чизилади:
- `___` → `<span class="rt-gap" role="img" aria-label="бўш жой">` (тагига чизилган бўш жой);
- `(сўз)` → `<span class="rt-bracket">(сўз)</span>` (қалин, `accent`);
- `[[сўз]]` → `<span class="rt-target">сўз</span>` (`accent-soft` фон ва таг чизиғи).

**Таржима машқида** (`translate`) сўзларнинг бош шакли `rt-hints` ичида «ўзбекча — русча» жуфти бўлиб туради.

**Қоидалар**
- Кўрсатма ўзбекча, турига қараб: «Қўшимчани ёзинг», «Қавсдаги сўзни керакли шаклда ёзинг», «Предлогни ёзинг», «Олмошни керакли шаклда ёзинг», «Сифатни мослаштиринг», «Белгиланган сўз қайси падежда?», «Кўпликда ёзинг», «Белгиланган сўзга савол беринг», «Хатони тўғриланг», «Русчага таржима қилинг».
- Русча гапда урғу белгилари бор, текширишда урғу ҳисобга олинмайди.
