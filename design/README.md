Ўзбек тилида гаплашадиган ўқувчилар учун рус тили сайти: Мавзулар, Машқлар, Луғатлар ва Тестлар. Услуб тоза ва ўқиш осон, ёшлар ва катталар учун (болаларча эмас). Мавзулар китобдек ўқилади; машқ ва луғат оддий карточкаларда туради. Асосий экран телефон (360–400px), сайт кўпинча Telegram ичидаги браузерда очилади.

## Матн ва тил

- **Интерфейс фақат ўзбекча, кирилл ёзувида.** Ў, Қ, Ғ, Ҳ ҳарфларини тўғри ёзинг. Интерфейсда лотин ёзуви ва инглизча сўз бўлмайди (код ва файл номлари бундан мустасно).
- **Савол ўзбекча, жавоб русча.** Луғат квизида ўзбекча сўз ва «Гапда: …» мисоли берилади, 4 та вариант русча.
- **Грамматик атамалар русча қолади:** родительный падеж, женский род, множественное число, прилагательное, глагол. Изоҳнинг ўзи ўзбекча.
- **Русча сўз ва гапларда урғу белгиси бор** (U+0301, бирлаштирувчи акут): `Звони́ть`, `в Ташке́нте`. Бир бўғинли сўзлар ва «ё» ли сўзлар белгисиз.
- **Қўшимчани ҳарфлар орқали тушунтиринг**, мавҳум атама билан эмас: «-а билан тугаган сўзда -а ўрнига -у қўйилади: ма́ма → ма́му».
- Оддий ва қисқа ёзинг. Ўқувчига «сиз» деб мурожаат қилинг: «Жавобни ёзинг», «Клавиатурани рус тилига ўтказинг».
- Тугма ёзуви феълдан бошланади: «Текшириш», «Кейинги →», «← Олдинги», «Билмайман, жавобни кўрсат», «Қайта топшириш».
- Вердикт: «Тўғри!» ёки «Хато». Ўтган саволни кўришда: «Бу машқда хато қилгансиз».
- Сонлар: «185 та сўз», «10 та савол», натижа «8/10». Сана: «18-ноябр». Тест номи: «Тест 1».
- Эмодзи ишлатилмайди. Ҳолат белгилари (✓/✗) иконка сифатида чизилади (Иконкалар бўлимига қаранг).

## Шрифтлар

- **Русча матн доим `ru` оиласида (PT Serif), ўзбекча матн `uz` оиласида (PT Sans).** Бу ўрганилаётган тилни кўрсатмадан бир қарашда ажратади. Русча матн ўраладиган элементга `lang="ru"` қўйинг: `bundle.css` даги `[lang="ru"]` қоидаси шрифтни ўзи алмаштиради, `speechSynthesis` ҳам тилни тўғри танийди.
- **Сарлавҳа ва рақамлар `display` оиласида (PT Sans Narrow 700)**, жумла ҳарфида: `title-xl` (h1), `title-lg` (h2), `title-md` (карточка), `verdict`, `numeral` («8/10»).
- Ўзбекча матн: `body` (17/26) изоҳ ва мавзу матни учун, `prompt-uz` (24/32) ўзбекча савол учун, `small` (15/22) таржима ва изоҳ қутиси учун, `caption` (13/18) мета ва навигация учун, `label` (12/16, катта ҳарф, 0.08em) «Изоҳ», «Мисол», «Жавобингиз» белгилари учун, `button` (17/24) тугмалар учун.
- Русча матн: `ru-word` (30/36) луғат карточкаси, `ru-sentence` (21/30) машқ гапи, `ru-option` (19/26) вариант, `ru-input` (19/26) жавоб майдони, `ru-example` (18/27) мисол гап, `ru-table` (16/22) жадвал катаги.
- **Жавоб майдонининг шрифти 16px дан кичик бўлмасин** (`ru-input` = 19px): акс ҳолда iOS экранни катталаштиради.
- Учала шрифт Google Fonts'дан юкланади: `PT Sans` 400/700, `PT Serif` 400/700/курсив, `PT Sans Narrow` 700. Улар ў, қ, ғ, ҳ ва урғу белгисини тўлиқ кўрсатади. ✓ ✗ ← → белгилари бу шрифтларда йўқ: ← → тугма ёзувида тизим шрифтидан олинади, ✓ ✗ эса SVG иконка бўлиб чизилади. Офлайн (PWA) учун шрифтларни сайтнинг ўзига қўйинг (woff2).

## Ранглар

- **Фон ва юза.** Саҳифа `bg`, карточка ва бошқарув элементлари `surface`, ичкари ботган жойлар (жадвал сарлавҳаси, изоҳ қутиси, прогресс изи) `surface-sunk`. Матн `ink`, иккинчи даражали матн `muted`.
- **`accent` ягона асосий ранг:** асосий тугма, танланган чип ва навигациядаги жорий бўлим, прогресс чизиғи, мисолдаги асосий сўз, жадвалдаги қўшимча, фокус. Тугма фони `accent`, ҳовери `accent-strong`, устидаги ёзув доим `on-accent` (қоронғи темада accent ёруғ, ёзув тўқ).
- **Тўғри ва хато ранги accent'дан алоҳида:** `good` / `good-soft` фақат «Тўғри», `bad` / `bad-soft` фақат «Хато». Улар accent ўрнига ҳеч қачон ишлатилмайди ва accent ҳеч қачон ҳолатни билдирмайди.
- **Ҳолат фақат ранг билан кўрсатилмайди.** Тўғри — ✓ иконкаси ва «Тўғри!» сўзи; хато — ✗ иконкаси, «Хато» сўзи ва вариант устидан чизиш. `good` ва `bad` бир-биридан ёруғлик билан эмас, ранг тони билан фарқ қилади, шунинг учун иконка ва сўзни ҳеч қачон олиб ташламанг.
- **`warn` / `warn-soft` фақат текширишдан олдинги огоҳлантириш учун** (жавоб бўш, лотин ҳарфи бор). Бу хато эмас, жавоб ҳисобга олинмайди.
- Чегаралар: безак учун `line` (карточка, вариант, жадвал қатори), бошқарув элементи учун `line-strong` (жавоб майдони, иккинчи даражали тугма, чип).
- Икки тема бор: «Ёруғ» (`light`) ва «Қоронғи» (`dark`). Тизим созламасини (`prefers-color-scheme`) кузатинг ва `data-theme` билан қўлда алмаштиришга имкон беринг. Ҳар бир матн жуфти иккала темада ҳам камида 4.5:1, чегара ва иконкалар 3:1.

## Оралиқ, бурчак, соя

- Оралиқлар 4px қадамли: `space-1` (4) … `space-12` (48). Саҳифа чети `space-4`, карточка ичи `space-5`/`space-4`, вариантлар орасида `space-2`, мавзу бўлимлари орасида `space-6`.
- Бурчаклар: ичкаридаги белгилар `radius-sm`, тугма/вариант/майдон `radius-md`, карточка ва жавоб панели `radius-lg`, чип ва белги `radius-pill`.
- Соя фақат карточкада (`shadow-card`) ва жуда енгил. Юзаларни чегара ажратади, соя эмас.

## Тузилма

- **Мобил биринчи ўринда.** Контент кенглиги `page-max` (640px) гача, марказда. Мавзу абзацлари `read-max` (68ch).
- **Пастки навигация доимий:** Мавзулар · Машқлар · Луғатлар · Тестлар (BottomNav), баландлиги `nav-height`. Бош саҳифада тўртала бўлим прогресси билан (SectionCard).
- **Кенг экранга мослашиш — иккита чегара.** Телефон кўриниши асосий ва ўзгармайди; қуйидагилар фақат экран кенгайганда қўшилади:
  - **≥ 700px (планшет):** саҳифа чети `space-6`, `page-max` 720px, рўйхатли саҳифаларда 920px (`rt-page--wide`). Карточка рўйхатлари (`rt-grid`) камида 290px'ли устунларга бўлинади; бош саҳифадаги тўртта бўлим доим иккита устунда (`rt-grid--2`). Сарлавҳа (h1) 38/42.
  - **≥ 1024px (компьютер):** пастки навигация чап устунга айланади (`rail-width` = 240px, тепасида сайт номи), саҳифа остидаги бўшлиқ йўқолади (`nav-bottom` = 0), рўйхатли саҳифалар 1040px гача кенгаяди, тугмалар панели (`rt-actionbar`) ёпишиб турмайди.
  - HTML ўзгармайди: навигация ҳам телефонда, ҳам компьютерда бир хил `<nav class="rt-nav">`, фақат услуби бошқа. Машқ, тест ва мавзу экранлари кенг экранда ҳам битта устунда қолади — матн ва саволни ўқиш осон бўлиши учун.
- **Машқ экрани тартиби:** TopBar (ортга, ном, прогресс) → машқ карточкаси (ExercisePrompt + AnswerField ёки OptionList) → Feedback → QuizNav → BottomNav. Тўлиқ кўриниши: ExerciseScreen.
- **Мавзу саҳифаси:** фақат матн ва жадвал (TopicBlocks, GrammarTable). Мавзулар бўлимида машқ ёки тест йўқ. Охирида «← Олдинги мавзу / Кейинги мавзу →».
- **Кенг жадвал ён томонга сурилади** (`rt-table-wrap`), саҳифа эмас.
- Ҳар бир босиладиган элемент камида `tap-min` (48px), вариант `option-min` (56px).

## Ҳолатлар ва ҳаракат

- **Автоматик ўтиш йўқ.** Жавобдан кейин изоҳ чиқади, «Кейинги →» ни фойдаланувчи ўзи босади.
- **«← Олдинги»** ўтган саволни фақат кўриш учун очади: жавоб ва изоҳ кўринади, қайта жавоб бериб бўлмайди.
- **Тест пайтида** тўғри ёки хато кўрсатилмайди: танланган вариант `is-selected`. Натижа ва ҳар бир савол таҳлили охирида (TestResult).
- Ҳаракат қисқа ва сокин: ранг ва чегара 150ms, прогресс 300ms, `ease`. Варақ йиртиш, сакраш ёки конфетти йўқ. `prefers-reduced-motion` ёқилган бўлса, барча ўтишлар ўчади.

## Клавиатура ва accessibility

- **Фокус доим кўринади:** `focus` рангида `focus-width` (3px) яхлит чизиқ, 2px оралиқ билан. Бу барча фон ва `*-soft` юзалар устида камида 3:1.
- Компьютерда: 1–4 — вариант, Enter — текшириш ва кейинги, ← / → — олдинги ва кейинги савол. Майдонга ёзилаётганда рақам тугмалари ишламайди.
- Жавобдан кейинги панел `role="status"`, огоҳлантириш `role="alert"`. Чип ва тестдаги вариант `aria-pressed`. Иконкали тугмада `aria-label` («Тинглаш»).
- Тинглаш (`speechSynthesis`, `ru-RU`): рус овози бўлмаса, тугма кўрсатилмайди.

## Иконкалар

- 24×24 чизиқли SVG иконкалар `assets/Icons` да: чизиқ 1.8px (✓ ✗ учун 2.4px), учлари юмалоқ, ранги `currentColor`. Улар саҳифага инлайн SVG сифатида қўйилади, шунда атрофдаги матн рангини олади.

- Иконка ҳеч қачон ёлғиз ўзи маъно ташимайди: ёнида сўз ёки `aria-label` бўлади.
