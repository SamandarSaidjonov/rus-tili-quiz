# Icons

24×24 чизиқли иконкалар, бир рангли (`currentColor`). `<img>` орқали қора кўринади; саҳифада инлайн SVG қилиб қўйинг ва рангни CSS `color` билан беринг: одатда `ink`, `muted` ёки `accent`, ҳолатда `good` / `bad` / `warn`.

- `speaker.svg` — тинглаш тугмаси (SpeakButton). Ранги `accent`.
- `book.svg` — Мавзулар бўлими.
- `pencil.svg` — Машқлар бўлими.
- `cards.svg` — Луғатлар бўлими.
- `test.svg` — Тестлар бўлими.
- `check.svg` — тўғри жавоб (✓), чизиғи 2.4px. Ранги `good`, танланган чипда `accent`.
- `cross.svg` — хато жавоб (✗), чизиғи 2.4px. Ранги `bad`.
- `alert.svg` — текширишдан олдинги огоҳлантириш. Ранги `warn`.
- `arrow-left.svg` — TopBar'да ортга қайтиш.
- `arrow-right.svg` — керак бўлса «Кейинги» йўналиши учун (тугма ёзувида одатда «→» белгиси).
- `chevron-right.svg` — бош саҳифадаги бўлим карточкасида ўтиш белгиси. Ранги `muted`.
- `sun.svg` / `moon.svg` — бош саҳифанинг ўнг юқорисидаги тема тугмаси: қоронғи темада қуёш
  (ёруғга ўтиш), ёруғ темада ой (қоронғига ўтиш) кўринади. Ранги `muted`.
- `trash.svg` — барча прогрессни тозалаш тугмаси. Ранги `muted`, устига борганда `bad`.
